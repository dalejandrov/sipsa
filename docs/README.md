# SIPSA Documentation

This directory contains diagrams for the SIPSA integration service.

## Diagrams

- **[ER Diagram](diagrams/er-diagram.puml)**: Database schema with entities and relationships
- **[Class Diagram](diagrams/class-diagram.puml)**: System architecture by layers (API, Application, Domain, Infrastructure)
- **[Component Diagram](diagrams/component-diagram.puml)**: Component interactions and dependencies
- **[Sequence Diagrams](diagrams/sequence/)**:
  - [Scheduled Ingestion](diagrams/sequence/scheduled-ingestion-sequence.puml): Automated data ingestion workflow
  - [API Query](diagrams/sequence/api-query-sequence.puml): Request/response handling with headers
  - [Manual Ingestion](diagrams/sequence/manual-ingestion-sequence.puml): Manual trigger process

## How to View

Use [PlantUML Online](https://www.plantuml.com/plantuml/) or IDE plugins (IntelliJ, VS Code).
